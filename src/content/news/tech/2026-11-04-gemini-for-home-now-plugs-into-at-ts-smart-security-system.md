AT&T's smart home security system has integrated with Gemini for Home. This integration allows users to access various Gemini-powered features, including summarizing home events and searching video history.

## Key facts
- AT&T's smart home security system now integrates with Gemini for Home.
- The Connected Life system is described as the "first" home security product to integrate with Google Home Premium.
- The integration enables features such as summarizing home events and searching video history.
