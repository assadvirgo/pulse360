The latest Windows 11 Insider build introduces new shortcuts for Xbox gaming mode and enhanced search features. These updates allow users to manage settings without leaving gaming mode.

## Key facts
- The new build adds powerful search features and quick settings for Xbox mode.
- Xbox shortcuts enable control over Bluetooth, WiFi, and power settings without exiting gaming mode.
- The search improvements allow filtering results for files, actions, or web results.
