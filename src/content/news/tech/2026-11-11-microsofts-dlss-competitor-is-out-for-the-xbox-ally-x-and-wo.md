Microsoft has announced the rollout of Automatic Super Resolution (Auto SR), an upscaling technology that competes with Nvidia's DLSS, for the Xbox Ally X, Xbox Ally X20, and select Windows Copilot Plus PCs. This official release includes new features that were tested earlier this year.

## Key facts
- Microsoft is rolling out Automatic Super Resolution (Auto SR) for the Xbox Ally X and Xbox Ally X20.
- Auto SR is also available for select Windows Copilot Plus PCs.
- The technology competes with Nvidia's DLSS.
- New features are included in this official release, following earlier testing in April.
