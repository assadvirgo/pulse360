OpenCode, an open source AI coding agent, has been targeted by hackers who accessed part of its online platform and stole some users' API keys. The platform is noted as a popular alternative to other coding tools like Claude Code and Cursor.

## Key facts
- Hackers accessed part of OpenCode's online platform.
- Some users' API keys were stolen.
- OpenCode is an open source AI coding agent.
- It is a popular alternative to Claude Code and Cursor.
