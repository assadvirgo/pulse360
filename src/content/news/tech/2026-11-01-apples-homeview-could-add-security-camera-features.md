Apple may be adding security camera features to its HomeView smart home hub, according to a discovery by a Reddit user. The hints were found in the HomeView 27.2 code, suggesting new functionalities related to security.

## Key facts
- The HomeView 27.2 code includes hints about a security camera mode.
- Features mentioned include motion detection, live streaming, and recording options.
- The code also references privacy functions related to the security camera features.
